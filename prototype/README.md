# Compensation calculator — Round 3 prototype ("the live estimate")

Static prototype of the approved landing page plus the complete calculator flow (phone + desktop), running a JavaScript port of the engine (rules 2026.10.0-draft).

- `index.html` — landing page (Figma: Final UI › Landing, story deck)
- `calculator.html` — the calculator: situation → 3 checks → age → work → family → injury → when → where → estimate ready → optional details → check answers → result → offer check → share
- Answers are stored in the browser only (localStorage). No backend.
- Not legal advice. Figures in the cases are from the judgments.

Deploy: static, root directory `prototype`.
